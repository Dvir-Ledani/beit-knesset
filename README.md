# אתר בית הכנסת

דף מידע לחברי בית הכנסת: זמני תפילות, עליות לתורה בשבת והודעות.

המידע מגיע מגיליון Google שרק הגבאים יכולים לערוך. כל עוד הגיליון לא מחובר (בקובץ `config.js`), האתר מציג נתוני דוגמה.

## מבנה הגיליון

| לשונית | עמודות |
|---|---|
| כללי | שדה, ערך (שורות: שם בית הכנסת, פרשה, תאריך) |
| זמנים | קבוצה (חול / שבת / כל קבוצה אחרת), תפילה, שעה, הערה |
| עליות | עלייה, שם |
| הודעות | תאריך, כותרת, תוכן, עד תאריך |

הודעה שתאריך ה"עד" שלה עבר נעלמת מהאתר. הודעה עם תאריך עתידי מופיעה רק כשהתאריך מגיע.
