# אתר בית הכנסת

דף מידע לחברי בית הכנסת: זמני תפילות, עליות לתורה בשבת והודעות.

המידע מגיע מגיליון Google שרק הגבאים יכולים לערוך. כל עוד הגיליון לא מחובר (בקובץ `config.js`), האתר מציג נתוני דוגמה.

## מבנה הגיליון

| לשונית | עמודות |
|---|---|
| כללי | שדה, ערך (שורות: שם בית הכנסת, פרשה, בעל קורא, תאריך, כניסת שבת, יציאת שבת, הנץ החמה היום, שקיעה היום) |
| זמנים | קבוצה (חול / שבת / כל קבוצה אחרת), תפילה, שעה (או "שעה לפני צאת שבת" וכדומה, מחושב לנתניה), הערה |
| עליות | עלייה, שם |
| פרשות | שבת (תאריך), פרשה. לוח ארץ ישראל עד סוף 2036; "פרשה" בכללי נשלפת מכאן לפי השבת הקרובה |
| הודעות | תאריך, כותרת, תוכן, עד תאריך |

הודעה שתאריך ה"עד" שלה עבר נעלמת מהאתר. הודעה עם תאריך עתידי מופיעה רק כשהתאריך מגיע.

כניסת ויציאת שבת מחושבות לפי מיקום נתניה (הדלקת נרות 20 דקות לפני השקיעה, יציאה כשהשמש 8.5 מעלות מתחת לאופק, שיטת NOAA). הנץ החמה (מעוגל למעלה) והשקיעה (מעוגלת למטה) מחושבים לכל יום באותה שיטה. החישוב נעשה גם בלשונית "חישוב זמנים" בגיליון וגם באתר עצמו, באותן נוסחאות, כך ששניהם מציגים אותה דקה.
